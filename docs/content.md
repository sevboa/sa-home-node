# Хранилище контента (`sa_home_node.content`)

Контент — тексты и данные, которые плагины получают по ключам, без
знания о владельце в ядре. `ContentStore(root)` читает файлы
`<root>/<плагин>.toml`; файл плагина читается один раз при первом
обращении к нему.

## Раскладка файлов

```
<root>/
  плагин-1.toml
  плагин-2.toml
```

## Ключи

Ключ — `"<плагин>.<имя>"`, значение — имя верхнего уровня из файла
плагина:

```toml
# плагин-1.toml
greeting = "Привет!"
menu = ["a", "b"]
```

- `store.get("плагин-1.greeting")` → `"Привет!"`;
- `store.get("ключ", default)` — значение по умолчанию;
- `"плагин-1.menu" in store` — проверка наличия;
- `store.require(["плагин-1.greeting", ...])` — одна `ContentError`
  со списком всех недостающих ключей в порядке запроса.

## Ошибки

`ContentError` (наследник `ValueError`) при:

- ключе без точки или пустых частях;
- отсутствии файла плагина — в тексте имя файла;
- битом TOML — в тексте имя файла.
