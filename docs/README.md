# sa-home-node: модули ядра

Оглавление:

- [architecture](architecture.md) — модули ядра, порядок старта и остановки ноды.
- [config](config.md) — конфиг ноды из TOML.
- [content](content.md) — хранилище контента плагинов по ключам.
- [plugins](plugins.md) — модель плагина, `ServiceSpec`, загрузка точек входа, контекст службы.
- [services](services.md) — службы: назначения, супервизор, процессная и встроенная службы, аренда синглтонов, пакеты настроек экземпляров и их репликация.
- [lifecycle](lifecycle.md) — жизненный цикл ноды: запуск, останов, питание, самоперезапуск, обновление.
- [monitor](monitor.md) — служба монитора: датчики, сканы, хранилище, экспозиция метрик.
- [host](host.md) — слой платформы: платформозависимое поведение ОС.
- [protocol](protocol.md) — протокол роя v0: транспорт, конверт, типы сообщений, действия службы `node`.
- [swarm](swarm.md) — рой: линки соседей, маршрутизация запросов.
- [cli](cli.md) — команда `sa-home-node`.
