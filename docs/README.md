# sa-home-node: модули ядра

Оглавление:

- [config](config.md) — чтение конфига ноды из TOML.
- [content](content.md) — хранилище контента плагинов по ключам.
- [host](host.md) — слой платформы: платформозависимое поведение ОС.
- [lifecycle](lifecycle.md) — жизненный цикл ноды: питание машины и перезапуск ноды.
- [plugins](plugins.md) — модель плагина, загрузка точек входа, контекст службы.
- [protocol](protocol.md) — протокол роя v0: транспорт, конверт, типы сообщений.
- [services](services.md) — аренда синглтонов между нодами, пакеты конфигураций экземпляров, их репликация между нодами.
- [swarm](swarm.md) — рой: линки соседей, маршрутизация запросов.
- [architecture](architecture.md) — модули ядра, порядок старта и остановки ноды.
- [cli](cli.md) — команда `sa-home-node`.
